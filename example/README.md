# Liquid AI LEAP Example

A simple chat application demonstrating the Liquid AI LEAP Flutter plugin.

## Getting Started

1. Ensure you have Flutter 3.24+ installed
2. Run `flutter pub get`
3. Connect a physical device (iOS or Android)
4. Run `flutter run`

## Features Demonstrated

- Model loading with progress tracking
- Streaming text generation
- Conversation management
- Generation statistics

## Device Requirements

- **iOS**: iPhone with iOS 15.0+ and 3GB+ RAM
- **Android**: Device with API 31+ and arm64-v8a ABI

## Notes

- The first run will download the model (~1GB)
- Model is cached for subsequent runs
- Physical device recommended for best performance
